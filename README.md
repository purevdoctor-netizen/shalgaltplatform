# Шалгалтын платформ (shalgalt-platform)

Сурагчийн **ӨМНӨХ (pre)** болон **ДАРААХ (post)** мэдлэгийн түвшнийг QR кодоор хэмжиж, үр дүнг автоматаар
тархааж шинжлээд **Word (.docx)** тайлан үүсгэн багшийн имэйл рүү илгээдэг вэб платформ.
Интернэттэй болон **интернэтгүй** ангид аль алинд нь бүрэн ажиллана.

## 1. Товч танилцуулга

|                 |                                                                                                       |
| --------------- | ----------------------------------------------------------------------------------------------------- |
| **Хэн ашиглах** | Багш (шалгалт үүсгэх, удирдах, тайлан авах) ба сурагч (QR уншиж хариулах)                             |
| **Нэвтрэлт**    | **Админ** багш бүрд данс нээж өгнө. Багш нэр/нууц үгээр нэвтэрнэ. Сурагч данс шаардахгүй              |
| **Гол урсгал**  | Шалгалт үүсгэх → QR → pre шалгалт → хичээл заах → горим солих → post шалгалт → анализ → .docx → имэйл |
| **Офлайн**      | PWA (Workbox precache) + Dexie/IndexedDB + sync engine. Тайлан, график, .docx бүгд браузерт үүснэ     |
| **Хэл**         | Бүх UI монгол кирилл (`i18n/mn.json`), англи хувилбар (`i18n/en.json`) сонголттой                     |

**Технологи:** React 18 · TypeScript (strict) · Vite · Tailwind · shadcn/ui · Dexie · Recharts · docx ·
Node 20 · Express · Prisma (SQLite dev / PostgreSQL prod) · Nodemailer · pnpm workspaces

> 🚀 **Бодит ашиглалтад 24/7 суулгах** (сургуулийн дотоод сүлжээ, Windows Service, нөөцлөлт):
> [`DEPLOY.md`](./DEPLOY.md) файлыг үзнэ үү.

## 3. Суулгах

```bash
# 1. Хамаарал суулгах (монорепогийн үндсэн хавтаснаас)
pnpm install

# 2. Орчны хувьсагч бэлдэх
cp .env.example .env          # Windows PowerShell: Copy-Item .env.example .env

# 3. Өгөгдлийн сан бэлдэх (dev = SQLite, файл болж үүснэ)
pnpm db:migrate
pnpm db:seed                  # жишээ шалгалт + 12 сурагч + demo.bagsh данс

# 4. Админ данс үүсгэх (түр нууц үгийг нэг удаа хэвлэнэ)
pnpm --filter @shalgalt/api admin:create
```

> **Эрхийн загвар:** Админ → багш нарын данс нээнэ → багш зөвхөн өөрийн шалгалтаа удирдана.
> Сурагч данс шаардахгүй. Дэлгэрэнгүйг [DEPLOY.md §5](./DEPLOY.md#5-хэрэглэгчдэд-түгээх).

`.env` дотор заавал шалгах зүйл:

```ini
DATABASE_PROVIDER=sqlite
DATABASE_URL="file:./dev.db"
WEB_ORIGIN=http://localhost:5173
SMTP_HOST=localhost
SMTP_PORT=1025
```

## 5. Гурван түгээх горим (deliveryMode)

Шалгалт үүсгэх үед аль нэгийг сонгоно. Энэ нь QR-д юу орох, өгөгдөл хаана хадгалагдахыг тодорхойлно.

| Горим           | QR агуулга                             | Хэзээ ашиглах                                | Горим солиход QR                                    |
| --------------- | -------------------------------------- | -------------------------------------------- | --------------------------------------------------- |
| **`online`**    | `https://<domain>/exam/<examId>`       | Ангид интернэт байгаа                        | **Өөрчлөгдөхгүй** — сервер `exam.mode`-ыг хэлнэ     |
| **`lan`**       | `http://<LAN-IP>:<port>/exam/<examId>` | Интернэт байхгүй, багш зөөврийн компьютертэй | **Өөрчлөгдөхгүй** — LAN сервер `exam.mode`-ыг хэлнэ |
| **`offlineQr`** | `<app-url>/#/x?d=<payload>`            | Интернэт ч, компьютер ч байхгүй              | **Дахин үүснэ** — payload дотор `mode` орсон        |

> **Чухал:** "нэг шалгалт нэг QR" зарчим `online` ба `lan` горимд хүчинтэй.
> Зөвхөн `offlineQr` горимд pre → post шилжихэд шинэ QR хэвлэх шаардлагатай.

### `offlineQr` горимын онцлог

- Шалгалтын бүх өгөгдөл (асуулт, хариулт) QR дотор **шахагдан** орно:
  `JSON → pako.deflateRaw → base64url`.
- Нэг QR-д хамгийн ихдээ **1200 байт**. Хэтэрвэл автоматаар хэсэглэж `1/3, 2/3, 3/3` гэсэн
  слайд болгон харуулна (3 сек тутам автоматаар солигдоно, гараар ч солино).
  Сурагчийн апп хэсгүүдийг IndexedDB-д хуримтлуулж бүгд цуглахад нэгтгэнэ.
- **25-аас олон асуулттай** шалгалтад QR хэт олон болох тул систем `lan` горимыг санал болгоно.
- Зөв хариултууд payload дотор **AES-GCM**-ээр шифрлэгдэж, зөвхөн "Илгээх" дарсны дараа тайлагдана.
  Дэлгэрэнгүйг [11-р хэсгээс](#11-аюулгүй-байдал-ба-хязгаарлалт) уншина уу.
- Сурагч дуусмагц дэлгэц дээр **хариулт-QR** гарна. Багш үүнийг өөрийн төхөөрөмжийн камераар
  уншиж цуглуулна. QR уншигдахгүй тохиолдолд **6 оронтой нөөц код** ашиглана
  (зөвхөн `single`/`truefalse` төрлийн, ≤10 асуулттай шалгалтад боломжтой).

## 6. LAN сервер (интернэтгүй анги)

Багшийн зөөврийн компьютер дээр бүтэн backend-ийг локалаар асааж, сурагчид Wi-Fi/hotspot-оор холбогдоно.

```bash
pnpm lan
```

Консол дээр иймэрхүү мэдээлэл гарна:

```
✔ LAN сервер ажиллаж байна
  Дотоод хаяг : http://192.168.1.42:3000
  Шалгалт     : http://192.168.1.42:3000/exam/<examId>
  Өгөгдлийн сан: file:./lan.db
```

**Алхмууд:**

1. Багшийн компьютерээс Wi-Fi hotspot тараах, эсвэл ангийн Wi-Fi-д багш болон сурагчид хамт холбогдох.
2. `pnpm lan` ажиллуулах.
3. Шалгалт үүсгэхдээ `deliveryMode = lan` сонгох → QR автоматаар LAN IP-г агуулна.
4. Сурагчид QR уншиж шалгалт өгнө. Бүх өгөгдөл `lan.db` дотор хадгалагдана.
5. Дараа нь интернэт гармагц LAN сервер өөрөө клиент болж, үндсэн сервер рүү `POST /api/sync`-ээр
   өгөгдлөө нийлүүлнэ (`.env` дотор `UPSTREAM_API_URL` тохируулсан тохиолдолд).

**Хязгаарлалт:** энэ горимд багшид Node ажиллуулах компьютер заавал хэрэгтэй.
Компьютер байхгүй бол [`offlineQr`](#5-гурван-түгээх-горим-deliverymode) горимыг ашиглана.

## 7. Имэйл — Mailpit (dev) ба SMTP (prod)

### Хөгжүүлэлт: Mailpit

Илгээсэн имэйлийг гадагш явуулахгүйгээр барьж авч, вэб дээр харуулна.

```bash
docker compose --profile dev up -d mail
```

|           |                       |
| --------- | --------------------- |
| SMTP порт | `localhost:1025`      |
| Вэб UI    | http://localhost:8025 |

`.env`:

```ini
SMTP_HOST=localhost
SMTP_PORT=1025
SMTP_SECURE=false
SMTP_USER=
SMTP_PASS=
SMTP_FROM="Шалгалтын платформ <noreply@shalgalt.local>"
```

> Docker байхгүй бол Mailpit-ийн binary-г шууд татаж ажиллуулж болно: https://github.com/axllent/mailpit/releases

### Production: жинхэнэ SMTP

```ini
SMTP_HOST=smtp.gmail.com
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=your@gmail.com
SMTP_PASS=<App Password>          # энгийн нууц үг БИШ, App Password
SMTP_FROM="Сургуулийн нэр <your@gmail.com>"
```

### Офлайн үеийн имэйл

Интернэтгүй үед тайлан үүсгэвэл `.docx` шууд татагдаж, илгээх хүсэлт `emailQueue` хүснэгтэд
`pending` төлөвтэй хадгалагдана. Интернэт холбогдмогц sync engine автоматаар upload + илгээнэ.
Багшийн хяналтын самбарт төлөв (**Хүлээгдэж буй / Илгээсэн / Алдаа**) болон "Дахин илгээх" товч харагдана.

## 8. Docker Compose

```bash
# Бүрэн стек (PostgreSQL + API + Web)
docker compose up -d --build

# Зөвхөн dev дэд бүтэц (PostgreSQL + Mailpit), код нь локалаар ажиллана
docker compose --profile dev up -d db mail

# Зогсоох
docker compose down

# Өгөгдөл хамт устгах
docker compose down -v
```

| Сервис | Порт        | Тайлбар                                                   |
| ------ | ----------- | --------------------------------------------------------- |
| `db`   | 5432        | PostgreSQL 16                                             |
| `api`  | 3000        | Express + Prisma (эхлэхдээ `prisma migrate deploy` хийнэ) |
| `web`  | 8080        | nginx, `/api/*`-г `api` сервис рүү дамжуулна              |
| `mail` | 1025 / 8025 | Mailpit (зөвхөн `dev` профайл)                            |

`db` сервисийг ашиглан локал кодоо ажиллуулах бол `.env`-ээ солино:

```ini
DATABASE_PROVIDER=postgresql
DATABASE_URL="postgresql://shalgalt:change_me_in_production@localhost:5432/shalgalt?schema=public"
```

## 11. Аюулгүй байдал ба хязгаарлалт

### Эрхийн загвар

| Хэн        | Данс                       | Эрх                                                          |
| ---------- | -------------------------- | ------------------------------------------------------------ |
| **Админ**  | Сервер дээр CLI-гаар үүснэ | Багшийн данс нээх/хаах, нууц үг сэргээх, бүх шалгалтыг харах |
| **Багш**   | Админ нээж өгнө            | Зөвхөн өөрийн шалгалт                                        |
| **Сурагч** | Данс шаардахгүй            | QR уншиж шалгалт өгөх                                        |

**Хэрэгжилт:**

- Нууц үг — Node-ийн built-in **scrypt** (native хамааралгүй), санамсаргүй salt-тай.
- Сесс — HTTP-only cookie; серверт зөвхөн токены **SHA-256 хэш** хадгалагдана.
- Түр нууц үг олгосон хэрэглэгч эхний нэвтрэлтэд **заавал солино** (бусад үйлдэл 403).
- Нууц үг солих/сэргээхэд тухайн хэрэглэгчийн **бүх идэвхтэй сесс тасарна**.
- Нэвтрэх оролдлого — 15 минутад 10 удаа (амжилттайг тоолохгүй).
- Системд **дор хаяж нэг идэвхтэй админ** заавал үлдэнэ.
- `examId` нь таамаглагдахгүй (nanoid, 12 тэмдэгт).
- Сурагчийн хуудас `/exam/:examId` нэвтрэлт шаарддаггүй.

**Хуваалцах линк:** шалгалт бүр `?t=<teacherToken>` линктэй хэвээр — хамтран ажиллах
багшид дамжуулбал нэвтрэхгүйгээр удирдана. Хаах бол `.env`-д `DISABLE_SHARE_TOKEN=true`.

> ⚠ **Админы нууц үг мартвал** сервер дээр сэргээнэ:
> `pnpm --filter @shalgalt/api admin:create -- --username admin --reset`

### `offlineQr` горимын мэдэгдэж буй хязгаарлалт

| Хязгаарлалт                                       | Тайлбар                                                                                                                                                                                                                                                                                                       |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Зөв хариулт төхөөрөмж дээр байна**              | Payload дотор шифрлэгдсэн зөв хариулт байх тул техникийн мэдлэгтэй сурагч онолын хувьд задлах боломжтой. AES-GCM түлхүүр нь payload-тай хамт явдаг учир энэ нь **криптографийн хамгаалалт биш**, зөвхөн санамсаргүй/энгийн харагдацаас хамгаалдаг. Өндөр эрсдэлтэй шалгалтад `online`/`lan` горим ашиглана уу |
| **Давхардлыг зөвхөн нэг төхөөрөмж дээр илрүүлнэ** | `offlineQr` үед "нэг сурагч нэг горимд нэг удаа" дүрмийг тухайн төхөөрөмжийн IndexedDB шалгадаг. Сурагч **өөр төхөөрөмж** ашиглавал давхар өгөх боломжтой. Багш хариулт цуглуулах үедээ `studentKey+mode`-оор давхардлыг илрүүлж хасна                                                                        |
| **QR тоо**                                        | 25-аас олон асуулттай шалгалтад QR хэт олон болно. Систем анхааруулж `lan` горимыг санал болгоно                                                                                                                                                                                                              |

### Сурагчийн хувийн мэдээлэл

`studentKey = sha256(овог|нэр|анги)` — тайлан болон sync-д хувийн мэдээлэл дамжуулахгүй байх зорилготой.
Харин нэр өөрөө `Submission` бичлэгт тусдаа хадгалагдаж, зөвхөн багшийн тайланд харагдана.
**Гуравдагч тал руу ямар ч сурагчийн мэдээлэл илгээгддэггүй.**

### iOS Safari

- PWA-г Safari дээр шууд нээхэд камер ажиллана.
- "Home screen-д нэмэх" (standalone) горимд зарим iOS хувилбар дээр камерын хандалт
  хязгаарлагддаг тул QR унших шаардлагатай хуудсыг **Safari дотроос** нээхийг зөвлөнө.
- Камер ажиллахын тулд хуудас `https://` эсвэл `localhost` дээр байх ёстой
  (LAN горимд `http://192.168.x.x` дээр камер ажиллахгүй — тиймээс сурагчийн QR уншилтыг
  утасны камерын апп/шууд линкээр гүйцэтгэнэ).

### Хамрахгүй хүрээ

Хэрэглэгчийн бүртгэл/нэвтрэлт · олон багшийн удирдлага · төлбөр · зураг/файл хавсаргасан асуулт ·
хэсэгчилсэн оноо (`multi` төрөлд) · fuzzy текст харьцуулалт · сурагчийн мэдээллийг гуравдагч тал руу илгээх ·
заавал онлайн байхыг шаардах алхам.

  тайлан илгээж http://localhost:8025 дээр шалгана.
