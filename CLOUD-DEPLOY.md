# Үүлэнд байршуулах — үнэгүй, домэйнтэй, HTTPS-тэй

Энэ баримт нь платформыг **интернэтэд гаргах** алхмуудыг тайлбарлана.
Бүх зүйл **үнэгүй**, **банкны карт шаардахгүй**.

> Сургуулийн дотоод сүлжээнд (LAN) байршуулах бол [`DEPLOY.md`](./DEPLOY.md) үзнэ үү.

---

## Юу ашиглах вэ

| Хэсэг         | Үйлчилгээ             | Үнэгүй эрх                                    | Карт          |
| ------------- | --------------------- | --------------------------------------------- | ------------- |
| Вэб + API     | **Render**            | 750 цаг/сар, HTTPS, `нэр.onrender.com` домэйн | ❌ шаардахгүй |
| Өгөгдлийн сан | **Neon** (PostgreSQL) | 0.5 GB, **хугацаагүй**                        | ❌ шаардахгүй |
| Код хадгалах  | **GitHub**            | хязгааргүй хувийн repo                        | ❌ шаардахгүй |

**Нийт зардал: 0₮**

### ⚠ Мэдэж байх ёстой 3 зүйл

1. **Сервер 15 минут ажиллахгүй бол унтдаг.** Дараагийн хүсэлт **30–50 секунд**
   хүлээнэ. Шалгалтын өмнө багш хуудсаа нээж «сэрээх» хэрэгтэй
   ([доор шийдэл бий](#сэрүүн-байлгах-үнэгүй)).
2. **Render-ийн үнэгүй Postgres 30 хоногийн дараа УСТДАГ** — тиймээс
   оронд нь **Neon** ашиглана.
3. **Сурагчид интернэттэй байх ёстой.** Интернэтгүй ангид LAN хувилбар илүү.

### Яагаад үүлэн нь LAN-аас давуу вэ

- **HTTPS** → апп доторх камер ажиллана (`offlineQr` хариулт цуглуулах), PWA суулгаж болно
- Компьютер асаалттай байлгах шаардлагагүй
- Хаанаас ч хандана — багш гэрээсээ тайлан авч болно

## 1. GitHub — кодоо байршуулах

Render нь Git repo-оос deploy хийдэг.

1. https://github.com/signup — бүртгүүлнэ (үнэгүй)
2. https://github.com/new → repo нэр: `shalgalt-platform` → **Private** сонгоно → **Create**
3. Компьютер дээрээ:

```powershell
cd C:\Users\purev.b\burtgel-web\shalgalt-platform

git init
git branch -M main
git add .
git commit -m "Шалгалтын платформ"

# <ХЭРЭГЛЭГЧ>-ийг өөрийн GitHub нэрээр солино
git remote add origin https://github.com/<ХЭРЭГЛЭГЧ>/shalgalt-platform.git
git push -u origin main
```

> Нэр/нууц үг асуувал: нууц үгийн оронд **Personal Access Token** хэрэгтэй.
> GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
> → Generate new token → `repo` эрхийг сонгоно.

> ⚠ `.env` файл **git-д ОРОХГҮЙ** (`.gitignore`-д байгаа). Нууц үг GitHub дээр гарахгүй.

## 2. Neon — өгөгдлийн сан

1. https://neon.tech → **Sign up** (GitHub-аар нэвтэрч болно)
2. **Create project**
   - Нэр: `shalgalt`
   - Postgres хувилбар: анхдагчаар
   - Регион: **Europe (Frankfurt)** — Render-ийн Frankfurt-тай ойрхон
3. Үүсмэгц **Connection string** харагдана. Дараах хэлбэртэй:

```
postgresql://neondb_owner:НУУЦҮГ@ep-xxx-xxx.eu-central-1.aws.neon.tech/neondb?sslmode=require
```

**Энэ мөрийг хуулж авна** — дараагийн алхамд хэрэгтэй.

---

## 3. Render — вэб сервис

1. https://render.com → **Get Started** → GitHub-аар нэвтэрнэ
2. **New +** → **Blueprint**
3. Өөрийн `shalgalt-platform` repo-г сонгоно → Render нь `render.yaml`-ыг уншина
4. **Apply** дарна

Render нь `sync: false` гэсэн хувьсагчдыг **асууна**. Дараах утгыг оруулна:

| Хувьсагч                   | Утга                                                                            |
| -------------------------- | ------------------------------------------------------------------------------- |
| `DATABASE_URL`             | Neon-оос хуулсан connection string                                              |
| `WEB_ORIGIN`               | `https://shalgalt.onrender.com` _(эхний deploy-ийн дараа зөв хаягаараа солино)_ |
| `BOOTSTRAP_ADMIN_USERNAME` | `admin`                                                                         |
| `BOOTSTRAP_ADMIN_PASSWORD` | Хүчтэй нууц үг (≥8 тэмдэгт) — тэмдэглэж авна                                    |
| `BOOTSTRAP_ADMIN_NAME`     | `Сургуулийн админ`                                                              |
| `SMTP_USER`                | Gmail хаяг (имэйл хэрэггүй бол хоосон)                                          |
| `SMTP_PASS`                | Gmail **App Password** (хоосон бол имэйл идэвхгүй)                              |
| `SMTP_FROM`                | `Сургуулийн нэр <таны@gmail.com>`                                               |

5. **Create** → эхний build 5–10 минут үргэлжилнэ

### Build дууссаны дараа

Render танд хаяг өгнө, ж: `https://shalgalt-abcd.onrender.com`

**Тэр хаягийг `WEB_ORIGIN`-д тавьж, дахин deploy хийнэ:**
Render → Environment → `WEB_ORIGIN` → зөв хаягаа бичнэ → **Save, rebuild**

## 4. Шалгах

```
https://таны-хаяг.onrender.com/api/health/ping     → {"ok":true,...}
https://таны-хаяг.onrender.com/api/health          → {"status":"ok","database":"ok",...}
https://таны-хаяг.onrender.com/login               → нэвтрэх хуудас
```

**Админаар нэвтэрнэ** (`BOOTSTRAP_ADMIN_USERNAME` / `BOOTSTRAP_ADMIN_PASSWORD`)
→ нууц үгээ солино → `/admin/users` → багш нарын данс нээнэ.

### ⚠ Нэвтэрсний дараа заавал хийх

Render → Environment → **`BOOTSTRAP_ADMIN_PASSWORD`-ыг УСТГАНА**
(нууц үг орчны хувьсагчид үлдэх нь аюултай). Админ данс аль хэдийн үүссэн тул
дахин хэрэггүй.

## Сэрүүн байлгах (үнэгүй)

Үнэгүй Render 15 минут ажиллахгүй бол унтдаг. Үнэгүй «pinger» ашиглан сэрүүн байлгана:

1. https://cron-job.org → бүртгүүлнэ (үнэгүй)
2. **Create cronjob**
   - URL: `https://таны-хаяг.onrender.com/api/health/ping`
   - Давтамж: **10 минут тутам**
3. Хадгална

> `/api/health/ping` нь өгөгдлийн сан руу **хандахгүй** тул Neon-ы
> 100 compute-цаг/сар зарцуулагдахгүй. `/api/health` руу битгий ping хийгээрэй.

**Тэмдэглэл:** Render-ийн үнэгүй эрх сард 750 цаг. Байнга сэрүүн байлгавал
744 цаг зарцуулагдана — яг багтана, гэхдээ хоёр сервис ажиллуулж болохгүй.

## Имэйл тохируулах

Render → Environment дээр:

```
SMTP_HOST   = smtp.gmail.com
SMTP_PORT   = 465
SMTP_SECURE = true
SMTP_USER   = таны@gmail.com
SMTP_PASS   = App Password (16 тэмдэгт, зайгүй)
SMTP_FROM   = Сургуулийн нэр <таны@gmail.com>
```

> **App Password авах:** [DEPLOY.md §5.1](./DEPLOY.md#51-имэйл-тохируулах)

Шалгах: админаар нэвтэрч `/admin/users` → «Имэйлийн тохиргоо (SMTP)» →
**Туршилтын захиа илгээх**.

## Нөөцлөлт

Neon нь автоматаар цэгийн сэргээлт (point-in-time restore) хийдэг —
үнэгүй тарифт **сүүлийн 24 цаг**.

Гараар нөөцлөх (компьютер дээрээ):

```powershell
# PostgreSQL client tools суулгасан байх шаардлагатай
pg_dump "postgresql://...neon.tech/neondb?sslmode=require" --format=custom --file=backup.dump
```

> ⚠ Гол өгөгдөл (шалгалт, хариулт) багшийн **браузерын IndexedDB-д** бас
> хадгалагддаг тул сан гэмтсэн ч бүрэн алдагдахгүй.

## Асуудал шийдэх

| Шинж тэмдэг                                    | Шалтгаан                                                   | Шийдэл                                                        |
| ---------------------------------------------- | ---------------------------------------------------------- | ------------------------------------------------------------- |
| Эхний нээлт 30–50 сек                          | Сервер унтсан                                              | Хэвийн. Pinger тохируулна                                     |
| `Application failed to respond`                | Build бүтэлгүйтсэн                                         | Render → Logs үзнэ                                            |
| `Environment variable not found: DATABASE_URL` | Neon холболт оруулаагүй                                    | Environment → `DATABASE_URL`                                  |
| Нэвтэрч чадахгүй                               | `BOOTSTRAP_*` тохируулаагүй, эсвэл админ аль хэдийн байгаа | Logs дээр «Админ данс үүслээ» гэж байгаа эсэхийг үзнэ         |
| Cookie хадгалагдахгүй                          | `WEB_ORIGIN` буруу                                         | Яг `https://...onrender.com` хаягаа бичнэ                     |
| Имэйл явахгүй                                  | App Password биш энгийн нууц үг                            | [DEPLOY.md §5.1](./DEPLOY.md#51-имэйл-тохируулах)             |
| `db push` алдаа                                | Neon холболт таслагдсан                                    | Connection string-д `?sslmode=require` байгаа эсэхийг шалгана |

## Хязгаарлалт (үнэгүй тариф)

| Зүйл                | Хязгаар     | Хэтэрвэл                            |
| ------------------- | ----------- | ----------------------------------- |
| Render ажиллах цаг  | 750 цаг/сар | Сервис зогсоно (дараа сард сэргэнэ) |
| Neon сангийн хэмжээ | 0.5 GB      | Бичих боломжгүй болно               |
| Neon compute        | 100 цаг/сар | Сан түр зогсоно                     |
| Render RAM          | 512 MB      | Процесс дахин асна                  |

**Тооцоо:** 1000 сурагч × 20 шалгалт ≈ 50 MB. 0.5 GB нь олон жилд хангалттай.

Хязгаараас хэтэрвэл эсвэл унтдаг нь тохиромжгүй бол:
**LAN хувилбар** ([DEPLOY.md](./DEPLOY.md)) — хязгааргүй, унтахгүй, мөн үнэгүй.
